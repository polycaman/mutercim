
# Mutercim

Mutercim, hikaye tabanlı öğrenmeyi destekleyen modern bir web uygulamasıdır. Kullanıcılar, interaktif hikayeler aracılığıyla yeni bilgiler öğrenebilir ve uygulama üzerinden deneyim kazanabilirler.

## Özellikler
- **Hikaye Tabanlı Öğrenme:** Kullanıcılar, farklı hikayeler üzerinden adım adım öğrenme deneyimi yaşar.
- **Modern Arayüz:** Vue.js ve Vite ile geliştirilmiş, hızlı ve kullanıcı dostu bir arayüz.
- **Kolay Kullanım:** Basit ve anlaşılır menüler ile herkesin rahatça kullanabileceği bir yapı.
- **Responsive Tasarım:** Mobil ve masaüstü cihazlarda sorunsuz çalışır.

## Kurulum
1. Bu projeyi bilgisayarınıza klonlayın:
	```bash
	git clone https://github.com/polycaman/mutercim.git
	```
2. Proje klasörüne girin:
	```bash
	cd mutercim
	```
3. Gerekli bağımlılıkları yükleyin:
	```bash
	npm install
	```
4. Uygulamayı başlatın:
	```bash
	npm run dev
	```
5. Tarayıcınızda [http://localhost:5173](http://localhost:5173) adresini açarak uygulamayı görüntüleyebilirsiniz.

## Kullanım
- Ana sayfada hikaye seçimi yaparak öğrenmeye başlayabilirsiniz.
- Her hikaye, adım adım ilerlemenizi ve öğrendiklerinizi pekiştirmenizi sağlar.
- Menüden farklı hikayelere geçiş yapabilirsiniz.
